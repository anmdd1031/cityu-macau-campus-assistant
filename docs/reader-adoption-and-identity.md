# 读取入口采用与导师身份字段修复（2026-10-26）

新增 `runtime/query.py` 的单次证据包、确定性导师关键词筛选、原文身份表格生成及草稿校验。主 Skill 前置调用命令，将原有适用范围与详细路由逐字迁移到 `references/routing.md`；学校事实未改写，资料核验日期未更新。README、使用指南、检索说明和 changelog 同步。

## 实现

- `bundle map`、`bundle fds-fees-mainland-2027`、`bundle iusd-phd-2026` 一次返回适用证据及原有来源。主题明确限定年份、类别，不是通用语义路由器。
- `mentors --query 计算机视觉 --level master` 实时解析本地原始表格，按方向/标签关键词与明确硕士导师资格筛选。当前数据返回 11 人，顺序沿用原表；CV 同义词口径固定公开，不宣称全部语义相关教师，不将候选顺序视为质量排名。
- `render --ids ... --sha256 ...` 生成姓名、资格、公开邮箱、官方主页四列原文表格。研究方向与匹配解释保留在结构化 records 中供表外解释，避免重新生成长表时改写身份字段。
- `check --ids ... --sha256 ...` 校验实际草稿的四列表格；可通过 UTF-8 文件或标准输入传入。任何改字、错配、重复行或额外表格行返回退出码 2 和规范表格。校验只覆盖此表格，不保证表外论述或后续编辑正确。
- 源文件版本改变则拒绝旧哈希，要求重新检索。所有入口仅用 Python 标准库、只读、无网络；未修改宿主全局配置或安装 MCP。无 Python 时仍直接读取 Markdown。

## 验证

22 项 unittest、Skill 格式校验和 Git 差异检查通过。测试包括真实眭相傑记录、历史错字“睭”、邮箱/主页串行、重复行、草稿标准输入、旧版本哈希、固定关键词候选集合，以及既有章节 ID 全库歧义回归。

沿用前次四道问题及测试提示，模型配置仍为 gpt-6-astra / medium，独立串行会话、只读、无网页查询，中文输出仍按原测试要求使用 ASCII JSON。初轮四题都采用了 query.py，相比前次 8 次中仅 2 次使用读取器，表明本次样本的入口采用改善；样本少且版本、日期不同，不能外推长期采用率。

初版长表测试后收窄为四列身份信息并补充明确字段名和真实草稿校验说明，随后只重测导师题。最终返回答案由本轮主 Agent 再次独立运行 check_table，`valid=true`；“眭相傑”在表格及解释中均正确。模型草稿检查并非仅把 render 输出直接传回，调用轨迹显示传入了实际待发送四列表格。

最终导师测试前的一次用量限制失败（12.79 秒）独立保留，不计入响应时间。额度恢复后完成重试。全部试验原始事件位于本地 `.cache/skill-entry-20261026/`，最终复测在其 mentor-final 下的 retry 目录；仅答案与摘要随文档发布，不上传宿主上下文日志。

## 尚存限制

这些改动修复了本轮验证的读取采用和身份字段错误，**没有证明整体响应提速**。地图比旧样本慢、学费近似、IUSD 较短，而最终导师题仍约 104 秒，高于前次约 82 秒平均。样本少、跨时间、答案长度及校验步骤不同，不能做因果归因。最终导师调用仍包含宿主记忆搜索、额外规则读取；本地 Skill 无法保证任意宿主不重复调用或校验后不再改写。

真实宿主若要强制保障输出，应在发送前调用同一表格校验器，失败时由程序渲染规范身份表格，不再交模型重写该部分。本轮只完成本仓库提供的接口与指引，没有宣称已替其他应用完成集成。
