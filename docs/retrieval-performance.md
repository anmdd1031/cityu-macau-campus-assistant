# Skill 检索优化验证（2026-10-22）

本轮实现可选的 Python 标准库章节读取器，查询无网络、无文件写入。索引每次从当前 Markdown 生成，避免静态索引过期；按需加载导师和联网维护规则，迁移内容逐字验证保留。未修改知识事实或审计日期，未改变宿主模型配置。

## 已完成的验证

- 8 项 unittest 通过：上级年份与适用范围、完整表格和备注、围栏代码中的伪标题、批量去重及来源、重复编号报错、超限不截断、文件变化即时可见、停用资料与越界路径、UTF-8/ASCII 往返及真实教师姓名、2026 级规则。
- Skill 格式校验与 `git diff --check` 通过。
- `SKILL.md` 从 11,637 降至 10,077 个 Unicode 字符，减少约 13.4%。导师及联网维护规则按任务必读，其他主规则保留。

## 本地读取量

统计正文 Unicode 字符数，包含返回的上级引言，不含 JSON 包装及主 Skill。全文件基线按不同文件去重；这些是阅读量差异，不是模型耗时提升。

| 问题 | 完整文件字符 | 选中字符 | 减少 |
|---|---:|---:|---:|
| 校园地图 | 1,058 | 1,057 | 0.1% |
| FDS 学费及新课程状态 | 159,125 | 2,585 | 98.4% |
| IUSD 2026 级规则、边界及来源 | 12,013 | 3,211 | 73.3% |
| FDS 完整名单及匹配规则 | 27,157 | 27,154 | 0.0% |

地图原本已是小文件，导师查询保留完整名单用于比较，不声称这两类正文显著压缩。新增匹配规则文件已计入导师读取量。正文末尾换行处理造成的少量差值不算有效优化。

本机对地图、学费、导师三种读取各独立启动 Python 10 次，进程启动至 JSON 输出的中位数分别约 204.5、204.5、207.3 毫秒。这只是本地工具开销，不包括 Agent 思考、工具往返、模型输入或答案生成时间，不是纯磁盘读取速度，也不能外推至其他宿主。

## 模型复测限制

沿用上一轮四道问题及相同的串行 `codex exec --ephemeral --json -s read-only` 测试提示，未切换模型。四次均返回 `You've hit your usage limit`，没有完成答案；失败耗时全部排除，不报告本轮模型加速百分比或通过率。需要额度恢复后重复完整测试，核对来源、年份、导师姓名和工具调用次数，才能评价端到端效果。

本地原始记录保存在 `.cache/skill-benchmark-20261022-after/`（忽略目录，不随仓库分发）。本报告只记录可复核结论。未验证 WorkBuddy、微信小程序、自动发现 Skill 或在线事实更新；下游固定快照须单独接入。
