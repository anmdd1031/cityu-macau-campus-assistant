# 章节唯一定位修复与复测（2026-10-22）

已在 `runtime/read_sections.py` 实现完整标题路径、版本绑定章节 ID 和超限子章节导航。继续采用 Python 标准库，保留标题、编号、整文件与批量读取接口；未改写学校知识原文或切换模型。

## 已解决的问题

- 目录为每个标题返回 `path`、`parent_line`、`id`。ID 为 `@完整SHA256:标题行号`，与文件名一起用于 `--select`。即使完整标题路径仍重复，ID 也能唯一定位当前文件中的标题。
- 支持 `path:["顶层标题","上级标题","当前标题"]` 精确路径选择。旧的短标题歧义返回候选 ID 和路径，仍不擅自取第一条。
- 文件修改后旧 ID 返回 `stale_id`，须刷新目录；不允许通过与 `*` 混用跳过旧 ID 检查。ID 是版本内定位符，不是跨版本永久标识。
- 超限返回 `over_limit`、子章节 selector、包含祖先说明的正文字符数及 `fits_budget`。批量叶章节超限也返回各叶章节，方便拆分批次；单个叶章节超限需显式提高预算，不截断正文。
- 在检索说明中落实简单事实、条件检查、教师科研、跨学院比较四类读取流程。它们是规则化指引，未训练 Adaptive-RAG 分类器，也未引入自动摘要树。

## 验证结果

全量按章节 ID 重复读取三次，验证选中章节行范围完整、输出片段与原文一致，并检测全部 ID 唯一性。26 份资料共 1,858 个章节，较之前新增的 1 个是检索说明中的流程章节。

| 项目 | 结果 |
|---|---:|
| 原先 270 个标题歧义章节 | 270/270 按 ID 默认预算直接读取成功 |
| 当前默认预算直接读取 | 1,856/1,858 |
| 整文件级超限 | 2，均返回有效子章节 |
| 新生指南超限导航 | 25 个可在默认预算读取的后代章节 |
| 导师官网证据超限导航 | 59 个可在默认预算读取的后代章节 |
| 成功章节内部读取及编码中位数 | 1.876 ms |
| 成功章节内部耗时 P95 | 3.207 ms |
| 各文件独立启动读取中位数的中位数 | 199.213 ms |
| 各文件独立启动读取中位数的 P95 | 209.925 ms |

超限顶层章节另外显式提高预算验证原文完整性；不计作默认预算成功。超限导航返回的子章节如果继续超限，则递归使用返回的选择器，直到能完整读取。全库读取过程前后文件哈希不变。

内部耗时包括解析、哈希、片段拼接和 JSON 编码，不含进程启动和模型推理；统计基于每案例三次耗时的中位数。CLI 每文件选取最大可成功章节，独立启动三次；与上一轮最大叶章节抽样范围不完全相同，不能作严格加速百分比对比。尚未进行模型端到端复测。

16 项 unittest 通过，含全库重复标题回归、同路径重复标题、旧 ID、错误 ID/路径、批量超限、子章节大小准确性及 CLI JSON 输出。Skill 格式与 Git 差异检查通过。
