# 按需问题路由

## 适用范围

本 Skill 仅回答澳门城市大学公开信息：

- 学校概况、办学性质、校史、校训、办学特色、规模与排名口径、校区及学校层面部门分工。

- 招生、报名、学费、奖学金、注册、体检、D 签注、逗留许可、宿舍、科研管理与资助、全球交流、暑期项目、创业就业服务和校园服务。
- 数据科学学院（FDS）本硕博课程、学分、转专业、师资、导师方向匹配、校内工作邮箱、教师主页、资格考试、学术成果和毕业要求。
- 商学院（FOB）工商管理、MBA、管理分析学硕士（MMA）、DBA、国际商务领袖实验班、4+1 项目、导师和毕业要求。
- 金融学院（FOF）应用经济学、金融学、金融科技、金融学博士课程、学分、导师、论文发表和毕业要求。
- 大健康学院（FH）社会工作、应用心理学、智慧养老与健康管理、导师和毕业要求。
- 教育学院（FE/SOE）教育学硕士、教学研究硕士、教育学博士、教育博士（公开状态须确认）、课程、学分、导师、论文和毕业要求。
- 法学院（FL/SOL）法学硕士、专业方向、课程、学分、导师、论文和毕业要求。
- 国际旅游与管理学院（FITM）国际旅游与酒店管理、国际款待与旅游业管理、国际酒店管理、国际旅游管理、酒店管理课程、学分、导师、项目报告、论文和毕业要求。
- 人文社会科学学院（FHSS）应用语言学、英语、葡萄牙语、中国文化研究、文化产业管理与文化产业研究课程、学分、学术活动、论文和毕业要求。
- 创新设计学院（FIAD）设计艺术、设计学和艺术学本硕博课程、学分、专业范畴、学术活动、成果发表、导师和毕业要求。
- 城市与可持续发展研究院（IUSD）城市规划与设计硕博课程、学分、学术活动、成果要求、导师和毕业要求。
- 葡语国家研究院（IROPC）葡语国家研究硕博、国际关系与政府治理硕士课程、学分、开题、论文、人员和毕业流程。
- 荣誉班（Honours Class）选拔、课程体系、导师指导、科研训练、实习、竞赛和毕业条件。
- 氹仔校区校内餐厅、菜单、价格、供应时段和用餐建议。
- 学校及澳门政府公开的办事流程、部门入口和恶劣天气安排。

## 参考资料路由

校园地图、教学楼分布、楼宇标识及找楼先读 `references/campus_map.md`，跨校区问题追加 `references/freshman.md` 第 3 节。地图资料包含图片转写的楼宇图例；不要只给链接、引用无关学院定位或宣称没有建筑资料。分清地图楼宇标识、教室编码和当前课表，不推断各学院固定使用哪栋楼。

校歌、校服和每周升旗问题读取 `references/campus_culture.md`；不要从普通校园生活或图书馆片段推断不存在。大健康学院院长及负责人读取 `references/fh.md` 第 4.1 节，保留名誉院长、执行副院长和课程主任的职务区别及核验限制。

询问如何联系学校或部门时，先读 `references/freshman.md` 第 16 节按事项联系表，再读对应业务章节；标明核验状态，不猜测邮箱，不把总机或活动专线称为部门专线，不承诺回复时限。
