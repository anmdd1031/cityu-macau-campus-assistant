### 0.1 本知识库的回答边界

本知识库适合回答：

- "澳门城市大学教育学院有哪些硕士/博士课程？"
- "教育学硕士（MEd）有哪些专业方向？需要修多少学分？"

- "毕业论文/项目报告有什么要求？"

不适合直接给出最终结论的事项：

- 当年准确学费金额、缴费截止日期、退款规则；
- 当年内地考研分数线、奖学金名单、是否补录；

- 最新课程表、具体开课老师、教室、考试时间。

这些事项应引导学生查看当年官方公告、学生系统、招生事务处或联系学院秘书。

## 1. 学院概况与课程体系

### 1.1 学院定位

澳门城市大学教育学院（School of Education，简称 SOE）成立于 **2014年**，是澳门城市大学专注于研究生教育的学院。

**核心特点**：
- **专注研究生教育**——学院自成立之日起不设本科课程，仅开设硕士和博士研究生课程；
- 每年经过严格挑选与审核，招收约 **150名硕士** 及 **60名博士** 研究生；
- 教学与学术研究并重发展，致力于为澳门及周边地区培养高层次教学、科研和教育管理人才；
- 以研究作指导，以科研促教学，教书育人重在育人。

### 1.2 学院面向学生的核心卖点

1. **专注研究生教育**：不设本科，所有资源集中于硕士和博士培养；
2. **多元化师资**：以专兼结合方式邀请国内外知名学者担任特聘教授；
3. **科研平台完善**：设有澳门全球教育研究与创新研究所（IMED）、人工智能教育研究创新实验室等；
4. **国际化视野**：课程强调国际视野和跨文化交流能力培养；
5. **学科排名提升**：教育学院科研教学双丰收，学科排名首登 THE 全球榜单。

## 2. 学生最关心问题总览：按层级速查

### 2.1 硕士、博士关键差异

| 项目 | 教育学硕士 MEd | 教学研究硕士 MTLR | 教育学博士 PhD in Education |
|---|---|---|---|
| 学制 | 2 年 | 2 年 | 3 年 |
| 总学分 | 39 学分 | 33 学分 | 50 学分 |
| 专业方向 | 3 个：教育行政管理、终身学习、教育资讯技术 | 2 个：课程与教学、资讯技术与教学 | 不分方向，但选修课3选1 |
| 毕业论文/项目 | 学位论文（12学分）+ 答辩 | 项目报告（9学分，行动研究/教学实务型） | 学位论文（40学分，不少于5万字）+ 答辩 |
| 入学研究计划要求 | 无明确要求 | 无明确要求 | 报名时须提交不少于3,000字研究计划 |
| 授课语言 | 中文辅以英语 | 中文辅以英语 | 中文辅以英语 |
| 授课形式 | 面授 | 面授 | 面授 |

### 2.2 对学生利益影响最大的规则

1. **入学年份规则优先**：课程结构、毕业要求和学分要求应以学生本人入学年度的课程计划/学生手册为准。
2. **论文 vs 项目报告**：MEd 要求学位论文和答辩；MTLR 采用行动研究或教学实务型项目报告。两者完成方式不同，不能混用。
3. **博士申请需研究计划**：PhD in Education 报名时须提交不少于3,000字研究计划。
4. **所有课程大纲以政府宪报为准**：大学保留权利取消开办报读人数不足的科目。
5. **不含教师专业资格培训**：教育学院所有课程均未包含澳门中小幼教师专业资格培训内容。
6. **往届内地生需考研成绩**：往届本科毕业生报考硕士需参加全国硕士研究生招生考试且初试总成绩过国家A类线。
7. **教育博士的审批页有滞后**：独立课程页仍保留待刊宪提示，但 2027/2028 内地硕博招生简章已列出该课程及学费。回答内地生该届招生时采用新简章；其他生源类别、实际报名入口和后续年度仍须另查招生系统，不要把旧提示当作当前内地简章未招生的结论。

## 3. 入学与招生：学生应关心什么

### 3.1 硕士入学要求

#### 共同学历要求

| 学生类别 | 学历要求 |
|---|---|
| 本地生 | 学士学位/应届学士毕业或相等程度 |
| 内地生 | 教育部认证的本科学历（学信网可查询）；国(境)外毕业须教育部留学服务中心网可查 |
| 香港、台湾地区及国际学生 | 学士学位或同等学历 |

#### 往届生附加要求

| 学生类别 | 附加要求 |
|---|---|
| 应届本科毕业生 | 报考所有硕士课程均不受考研限制 |
| 往届本科毕业生（内地生） | 需参加2026年全国硕士研究生招生考试且初试总成绩过国家A类线 |

#### 专业背景偏好

- 专业不限，具**教育相关专业背景优先**。

#### 录取原则

大学根据**面试成绩**，综合以下因素择优录取：
- 专业背景
- 工作经历
- 学术成果
- 获奖经历
- 前置学历成绩
- 前置学历院校层次
- 英文能力

### 3.2 博士入学要求

#### 教育学博士（PhD in Education）

| 项目 | 要求 |
|---|---|
| 学历要求 | 硕士学位或同等学历 |
| 研究计划 | 报名时须提交不少于**3,000字**研究计划 |
| 录取标准 | 根据面试成绩，综合专业背景、工作经历、学术成果、获奖经历、前置学历成绩、前置学历院校层次、英文能力等择优录取 |

# 第一部分：硕士课程详解

## 5. 教育学硕士学位课程（MEd）

### 5.1 课程总览

| 项目 | 详情 |
|---|---|
| 课程名称 | 教育学硕士学位课程 |
| 学术范畴 | 教育学 |
| 修读模式 | 全日制 |
| 正常修业期限 | 两年 |
| 授课形式 | 面授 |
| 授课语言 | 中文辅以英语 |
| 授课时数 | 每学分授课15小时 |
| 总学分 | 最少39学分 |

### 5.2 课程特色

- 专注于提升学生在高等和基础教育领域所需的知识、技能及专业态度；
- 弥补澳门及周边地区高层次教育人才的不足；
- 全面学习教育学基础理论知识与技能，向多个细分专业方向拓展；
- 毕业生可增强职业竞争力，成为与社会发展相适应的教育研究中坚人才。

### 5.3 课程目标

1. 培育课程与教学研究的优秀人才；
2. 培育资讯科技研究的优秀人才；
3. 培育成人教育/终身学习领域的教学与管理人才。

### 5.4 学分结构

| 组成部分 | 学分 |
|---|---|
| 基础科目（必修） | 18 |
| 专业范畴科目 | 9 |
| 论文 | 12 |
| **总计** | **39** |

### 5.5 基础科目（必修，18学分）

| 科目 | 学分 |
|---|---|
| 教育机构的行政管理与领导 | 3 |
| 全球化，社会与教育 | 3 |
| 教育政策 | 3 |
| 教育研究方法 | 3 |
| 资讯科技与学习 | 3 |
| 教育人力资源管理 | 3 |

### 5.6 专业范畴科目（9学分）

课程设有 **三个专业方向**，学生须完成9学分：
- 两门已选专业范畴科目（6学分）
- 一门其余专业范畴科目（3学分）
- ⚠️ 学生只可选择每专业范畴的"作业项目"或者"管理层实习"其中一科

#### 方向一：教育行政管理

| 科目 | 学分 |
|---|---|

| 变革管理 | 3 |
| 教育行政管理作业项目 | 3 |
| 管理层实习（教育行政管理） | 3 |

#### 方向二：终身学习

| 科目 | 学分 |
|---|---|
| 成人教学策略 | 3 |
| 社区与成人教育课程规划 | 3 |
| 成人教育作业项目 | 3 |
| 管理层实习（终身学习） | 3 |

#### 方向三：教育资讯技术

| 科目 | 学分 |
|---|---|
| 多媒体技术教学的应用与开发 | 3 |
| 视听教材设计 | 3 |
| 教育资讯技术作业项目 | 3 |
| 管理层实习（教育资讯技术） | 3 |

### 5.7 毕业要求

1. 完成9门科目并取得 **27学分**；
2. 完成毕业论文，并通过硕士学位论文的答辩，取得 **12学分**；
3. 没有任何欠费；
4. 遵守本大学的规则。

### 5.8 预期学习成果

1. 应用课程与教学领域之专业技能，进行文献与实务的省思与批判；
2. 统整课程与教学理论与实务技能，进行研究、思考与批判；
3. 探究课程与教学议题并进行论文发表；
4. 对课程与教学的研究发现能进行创新与实践。

### 5.9 毕业生出路

1. 各大专院校教职，从事学术研究及教学工作；
2. 各级教育研究机关之研究人员或行政人员；
3. 学校行政管理工作；
4. 各机关教育培训专业人员。

### 11.2 MEd / MTLR 开题要求（教育学院 2026 专属规范）

- 教育学院当前链接的硕士通用开题指南要求正文不少于 **3,000 字**，一般包括研究背景与意义、研究现状、研究目标与内容、难点及解决方案、预期成果、工作计划、参考文献七部分；题目通常不超过 25 个中文字。
- 学院 2026 硕士专属规范进一步要求：系统梳理文献和研究缺口，明确理论/概念框架及研究问题或假设；实证论文应以定性、定量或混合方法取得的数据为基础。使用开放数据时，也须体现研究工具或方法创新，不能只做资料拼接。
- 研究设计应交代参与者/样本、抽样、工具（并在附录提供）、数据收集与分析、实施步骤，以及伦理和参与者保护；格式采用 APA 第 7 版，并按学院要求处理标点、分页、图表编号。
- 学院规范明确把大范围 AI 生成、伪造资料或低质量内容列为不能参加开题答辩的情形；即使只发现一条 AI 生成或捏造的参考文献，也会触发同样后果。Agent 不得把“润色可用”扩张为“可让 AI 代写或生成引文”。
- MEd 最终走学位论文路径；MTLR 走行动研究或教学实务型项目报告路径。两者可共用学院开题模板，但学分、成果形式和后续评审不能混用。

### 11.3 PhD in Education 开题要求

- 研究生院当前博士开题指南要求正文不少于 **5,000 字**，题目一般不超过 25 个中文字，正文同样按背景与意义、研究现状、目标与内容、难点与方案、预期成果、工作计划、参考文献七部分组织。
- 研究现状宜重点覆盖近 3–5 年研究；研究目标宜用不超过 150 字的一句话概括，每项研究内容宜控制在 150 字以内；计划表须涵盖中期检查、论文撰写和答辩，并采用最新版 APA 及学术出版规范。
- 教育学院 2026 博士专属规范用 11 项标准审核，包括：问题清晰且具原创/创新性、背景充分、达到博士范围与深度、文献与缺口系统、理论框架恰当、方法和样本/工具有理据、流程可操作、预期贡献、难点及解决方案、甘特图/进度计划、结构和引文完整严谨。
- 教育学院模板页仍同时链接一份 2023 年通用博士指南；遇到相同事项时，优先采用研究生院当前 2026 文件和学院 2026 专属规范，旧文件只作为仍在官网保留的历史附件。

### 11.4 教育学院学术伦理审查

学生为毕业论文或项目报告申请学院伦理审查时：

1. 须先通过开题答辩，并取得导师同意；申请人承诺以澳门城市大学为署名机构。
2. 伦理申请应在研究方法设计完成后、数据收集开始前提出，学院提示审查约需 1 个月。
3. 以电邮提交导师同意证明、伦理申请表/声明、研究计划和研究工具（例如知情同意书、问卷），以及适用的补充材料。
4. 校内导师指导的学生还须向教育学院办公室提交导师亲笔签署的申请表正本。
5. 文件名使用 `学号_中文姓名 英文姓名_文件名称` 格式；页面所列 2025/2026 会议及截止日期仅是历史日程，其他学年不得沿用。

### 11.5 版本与适用边界

- 表格编号长期存在不代表附件版本永久有效。每次提交前从研究生院当前“在读资讯”页和教育学院模板页重新下载。
- 课程页的五万字博士毕业论文要求，与开题报告的五千字最低要求是两个阶段，不能混为一谈。

## 12. 论文发表要求

教育学院公开课程页**未列明强制发表要求**；毕业核心为学位论文/项目报告。

但需注意：
- 部分导师可能鼓励或建议学生在读期间发表论文；
- 如学生有志于继续攻读博士或进入学术界，建议提前规划发表；
- 教育学院学科排名首登 THE 全球榜单，发表成果有助提升学术竞争力。
