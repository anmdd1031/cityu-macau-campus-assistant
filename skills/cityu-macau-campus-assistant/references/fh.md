## 1. 学院概况与课程体系

### 1.1 学院定位

澳门城市大学大健康学院（Faculty of Health，简称 FH）成立于 **2024年3月28日**。学院中文官网将其介绍为“全国乃至全球首家以大健康命名的专业教育和学术机构”；该表述属于学院官方定位，不应脱离来源扩展为独立排名或比较结论。学院以培养大健康产业所需的专业人才为目标，秉持"服务澳门、融入湾区"的社会责任，遵循"明德、博学、尚行"的校训精神，配合澳门特区政府"1+4"产业多元发展策略及深合区发展政策。

学院官方介绍中明确列出以下学位体系：

| 层级 | 官方公开课程体系 |
|---|---|
| 本科 | 社会工作学士（BSW） |
| 硕士 | 社会工作硕士（MSW）、应用心理学硕士（MAP）、智慧养老与健康管理硕士（学院已公布拟于 2026/2027 学年开办；页面仍标注“即将获批”） |
| 博士 | 应用心理学博士（DAP） |
| 未来规划 | 进一步拓展健康领域相关课程 |

> **旧课程页边界（2026-07-31 核验）**：创新社会工作系旧站仍可访问“社会科学学士”课程页（https://disw.cityu.edu.mo/en/list-22/31），页面描述心理学、社会学、政治学等多学科内容，并采用旧式阶段/10 学分结构。但该课程不在大健康学院当前课程清单，也不在 2026/2027 招生课程清单中。该页只能作为历史资料，不能回答为当前可申请课程。

> **年报时间边界（2026-07-31 核验）**：学院《2024/2025 学年年报》的学生、教职员和课程统计截止 2025 年 5 月底，招聘人数及新课程均属当时计划。年报同时出现特聘教授人数前后不一（正文称 2 名、表格列 4 名）等编辑差异，因此不得用它覆盖当前师资分类页、课程页或 2026/2027 招生简章，也不得把计划招聘或申报中的课程回答为已落实。

### 1.2 学院面向学生的核心卖点

从学生利益角度，FH 的公开资料中可提炼出以下要点：

1. **学院官网定位**：官网将其介绍为以“大健康”命名的专业教育和学术机构，专注大健康产业链人才培养。
2. **本硕博贯通路径清晰**：本科可衔接 MSW、MAP、DAP 或其他相关研究生学习。
3. **两大核心领域**：社会工作（创新社会工作系）与应用心理学（心理分析研究院）并重发展。
4. **国际化师资**：教师团队具备海外学位和前沿研究背景，部分教师来自葡萄牙、美国、英国、澳洲等地。
5. **实践导向**：强调理论研究与实际应用相结合，提供实习、督导、国际交流等机会。
6. **科研平台完善**：设有心理分析研究院、多个研究中心和实验室，支持学生参与科研项目。
7. **区域需求对接**：课程设置紧贴澳门、内地及周边区域在大健康领域的重大需求。

### 2.2 对学生利益影响最大的规则

1. **入学年份规则优先**：课程结构、毕业要求和学分要求应以学生本人入学年度的课程计划/学生手册为准。
2. **实习是社工专业的重要组成部分**：BSW 和 MSW 学生需完成规定时数的实习，并参加实习督导。
3. **论文/毕业项目是硕士/博士毕业核心**：需提前规划论文选题、导师匹配和写作进度。
4. **老年学与社会服务管理是 MSW 的特色方向**：学生应在入学后尽快了解并选择适合自己的专业方向。
5. **应用心理学强调中国文化建设与心理分析视角**：MAP 和 DAP 学生需具备中国文化背景知识，并对心理分析、积极心理学等有基本了解。
6. **选修课可能因人数不足不开课**：需准备备选课程。

## 3. 入学与招生：学生应关心什么

### 3.1 本科入学：常见身份类型

澳门城市大学招生通常按身份类型分流，包括但不限于：

- 澳门本地生；
- 中国内地学生；
- 香港、台湾地区学生；
- 国际学生。

| 学生类别 | 公开页面显示的基础要求 |

| 本地/国际学生 | 高中毕业或同等学历 |
| 中国内地学生 | 高中毕业，并参加当年全国普通高等学校统一招生考试（夏季高考） |

# 第一部分：本科生关切

## 5. 本科课程详解：社会工作学士（BSW）

### 5.1 课程总览

澳门城市大学大健康学院本科课程以"社会工作学士（BSW）"为主轴，旨在培养拥有高专业适应能力的本地化社会工作人才。课程强调科研基础、理论教学与实践手法相结合，推动社会工作往学术化、专业化及国际化发展。

**课程成立时间**：2016年5月17日（注：大健康学院成立于2024年，但社会工作系历史更久）

### 5.2 课程特色

| 特色 | 说明 |
|---|---|
| 重视多元教学方法 | 结合理论、实务、实习、国际交流等多种形式 |
| 全人发展 | 针对学生在社会工作专业上的全人发展 |
| 国际学术交流 | 推动本地及海外实习课程，促进国际学术交流活动 |
| 研究为基础 | 以研究为基础，结合理论、实务经验及社会未来发展来建构课程设计与教学 |
| 前瞻性培育 | 建构国际学术交流平台，培育学生具前瞻性、创意性的社会服务概念 |

### 5.3 学生核心能力

| 核心能力 | 说明 |
|---|---|
| 国际专业水平 | 培养具国际专业水平的社工人才，以应对澳门的社会需要 |
| 知识应用与学术研究 | 强调知识之实际应用，同时着重发展学生的学术研究能力 |
| 多领域专业知识与技能 | 掌握各个社会工作领域的专业知识及技能，包括：老人社会工作、医务社会工作、家庭社会工作、复康社会工作、多元文化社会工作、社会服务管理 |
| 多角度视野 | 能以多角度和广阔视野认识社会工作，并对社会不同情况进行理性和专业分析 |

### 5.4 师资特色

- 师资主要由本地及国内外知名大学的教授组成；
- 各教学人员均具备社会工作及其相关领域丰富的前线实务经验、社会服务管理经验及相当科研学术能力；
- 学院会邀请外地专家开办讲座、研讨会和工作坊，丰富学生的学习历程；
- 重视学生人格和社会工作专业伦理的培育，以关注弱势群体、倡导社会公义及宣扬社工价值为目标。

### 5.5 毕业出路

#### 就业方向

| 领域 | 具体岗位/机构 |
|---|---|
| 公共行政 | 公共行政服务单位 |
| 社会福利 | 各公私立社福机构、医疗单位、企业组织之社工人员 |
| 人力资源 | 各工商机构之人力资源管理人才 |
| 非营利组织 | 各非营利组织之管理人员 |
| 其他相关 | 公共关系、研究分析等性质工作 |

#### 进修方向

- 继续进修深造与社会工作相关之硕士及博士课程。

## 6. 本科实习与教学实践

### 6.1 实习科目介绍

社会工作学士课程包含实习科目，旨在让学生将课堂所学应用于实际社会服务场景。实习科目介绍详见：https://disw.cityu.edu.mo/list-23/34

### 6.2 实习要求

- 学生需完成规定时数的实习；
- 实习期间需参加实习督导；
- 实习结束后需提交实习报告。

> 注意：具体实习时数、督导要求、报告格式等以课程手册和实习科目介绍为准。

### 6.3 教学实践

学院强调多元教学方法，包括但不限于：

- 课堂教学；

### 11.3 2025 年开题报告写作指南

学院论文文件入口现同时提供传统型论文与三篇文章型博士论文的开题指南，均标为 `Sep 15, 2025 v1`：

| 适用形式 | 当前指南要点 |
|---|---|
| 硕士论文/传统型博士论文 | 开题报告建议约 8,000 字以上；摘要约 300 字、不得超过 500 字或一页且不分段；主体覆盖研究背景与问题、目的和研究问题、文献综述与理论架构、研究方法、伦理、资料分析及计划等 |
| 三篇文章型博士论文 | 开题报告同样建议约 8,000 字以上；除总体绪论外，须逐篇列暂定题目、文献缺口、目的/问题/假设、方法、资料与分析、创新贡献和拟投期刊，并交代共同作者、责任、伦理及资料取得 |

这些是开题报告结构要求，不替代各课程手册对“入学后何时开题”的时间节点，也不表示达到建议字数就会自动通过。

### 11.4 三篇文章型博士论文的适用边界

学院另行发布的 `Sep 15, 2025 v1` 补充规定把三篇文章型博士论文界定为一个主题一致的整体，要求含摘要、整合性绪论和完整文献回顾、三篇文章，以及整合三篇发现的讨论与结论。关键限制包括：

- 三篇文章须达到可投稿水准，并由答辩小组认可；至少两篇须基于学生分析的原始资料；文件后文允许第三篇为与整体主题紧密相关的概念研究或系统性文献回顾；
- 若文章投稿或发表，学生须为第一作者并主导构想、设计、写作、研究实施和资料分析；不得与其他学生共同署名，其他共同作者的角色与贡献比例须披露；
- 所有共同作者资料须在开题阶段呈报并获答辩小组同意，使用已发表内容还须取得授权；
- 最多纳入一篇在博士期间、开题答辩后发表或录用并符合主题的文章；
- 与传统论文一样，至少在论文答辩前四周把全部文章交答辩小组审阅；开题获批后如改变论文内容或形式，须提交修订开题报告并获开题小组同意。

同一补充文件开头写“至少三篇实证研究文章”，后文又明确允许第三篇为概念研究或系统性综述，存在内部口径张力。Agent 应如实说明并要求学生向学院确认其届别适用解释。该文件只规范选择三篇文章型论文者，不能据此回答“所有 DAP 学生都必须已发表三篇文章”。

### 11.5 硕博论文格式补充规定

学院 `Sep 15, 2025 v1` 格式补充规定还要求：

- 不得直接粘贴 SPSS 或 Excel 截图；表格采用 APA 三线表，图表须重新排版、对齐并保持简洁；
- 图表置于相关完整段落之后；跨页表格使用重复表头，过宽表格应拆分；表题在上、图题在下并连续编号；
- `p`、`t`、`F`、`r`、`z` 等统计符号用斜体，报告检验方法、变量、自由度、效应量与显著性；`p < .001` 不得写成 `.000`；
- 中英文标点和字体按语言区分，专有名词首次出现给出英文全称与缩写；
- 文件要求错别字不得超过五处，摘要不得出现参考文献。

### 11.6 论文流程建议

1. **提前联系导师**：不要等到开题才联系；第一学期就可以开始了解教师研究方向；
2. **选题要具体**：避免选题过大；确保能在规定时间内完成；
3. **定期与导师沟通**：至少每月一次；及时汇报进展和困难；
4. **查重和格式要提前检查**：避免最后时刻出问题；
5. **保留所有表格副本**：答辩后可能需要归档。

### 17.4 涉及研究参与者的伦理审查

大健康学院“伦理审查”专区公开了行为与社会科学研究伦理相关材料。当前《研究参与者知情同意书》模板要求研究者按项目实际情况填写并向参与者说明，包括研究目的、参与条件、研究流程、限制、潜在风险与救济、研究效益、商业利益、材料保存与保密、损害补偿、退出方式和参与者权利等内容；不适用的项目应注明“不适用本研究”，不应直接删除栏目。

当前《伦理审批申请表》将审查分为免除审查、简易审查和全面审查三类。即使项目主持人自行判断可能符合免除审查，也仍须送审，由伦理审查委员会确认并开立免审证明；不得自行把“低风险”解释为无需提交。

模板还明确：

- 参与研究应为自愿行为，参与者可撤回同意或退出；
- 可识别身份和隐私资料须说明保护、保存期限和届期处理方式；
- 知情同意书应由项目主持人或受过训练的研究团队人员说明，并由参与者审慎考虑后签署；
- 涉及未成年人、无行为能力或限制行为能力参与者时，须由法定代理人按模板签署；
- 伦理审查和知情同意属于项目审批事项，模板本身不代表某个研究已经获批。

学院《学生论文研究伦理申请和审查指引》（2025-10-23 v3）列出的当前学生申请流程为：

1. 指导老师作为首席研究员（PI）、学生作为共同首席研究员（Co-PI），两者共同签署申请表和研究方案并承担合规责任；
2. 通过电子表单提交伦理申请表、研究方案，以及适用的问卷/访谈大纲、知情同意书、招募材料和其他文件；文件保存为 PDF、压缩上传，并按“姓名_学号_文件名”命名；
3. 每月最后一个工作日为当月提交截止，先进行材料和格式的形式审查；
4. 学院伦理委员会指派两位委员进行内容审查，关注研究设计、招募与数据收集、风险与利益、隐私保密和知情同意；申请须获全体审查委员通过；
5. 审批约需 20 个工作日，由委员会主席根据审查结果作最终决定，并以邮件或书面方式发出审批函；
6. 研究方案发生重大变更或出现伦理问题时，应立即报告伦理委员会。

Agent 不应提供“无需伦理审查”或“使用模板即可自动获批”的判断；项目负责人应从学院伦理审查专区下载最新表格，并向学院伦理审查小组确认适用程序。
